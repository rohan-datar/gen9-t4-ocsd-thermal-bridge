# ML350 Gen9 + Tesla P100 (`ml350-gen9-p100`)

Tested by Rohan Datar, November 2026.

| | |
|---|---|
| Chassis | HPE ProLiant ML350 Gen9 (tower), one Xeon E5-2680 v4 |
| Firmware | iLO 4 v2.82, System ROM P92 v2.60, BIOS Optimal Cooling |
| Fans | stock; one fan moved so that two fans (bays 4 and 8) feed the PCIe slot 3 zone |
| GPU | NVIDIA Tesla P100 PCIe 16 GB, passive, in slot 3 at `00000000:0a:00.0` (OCSD bus 10, device 0), 3D-printed intake duct, driver 580.196.07, 140 W power cap |
| OCSD layout | 3 native records (560SFP+ bus 4, BCM5719 bus 2, P440ar bus 3); the GPU uses record 3, count 3 -> 4 |
| iLO sensor | `27-PCI 3`, reading GPU + 15 C |
| iLO check | 15 s IPMI timeout, 6 consecutive misses |
| Publish offset | 10 C in use (iLO reads GPU + 25 C) |

## Notes

- **Registration.** iLO showed `27-PCI 3` only after an iLO reset with the
  daemon publishing, and the sensor was gone again after every host power
  cycle. A daemon restart without a power cycle kept it.
- **iLO check tolerance.** With the original 5 s / 2-miss check, in-band IPMI
  queries timed out often enough under load (the BMC busy with ramped fans)
  that the daemon declared the sensor lost and exited twice in one benchmark.
  With the record then stale, iLO ran the fans at 100%. The profile uses 15 s
  and 6 misses.
- **Fan curve.** At 160 W with no offset, the two slot-3 fans rose together
  to only about 47% while the GPU reached 75-77 C; the fans had headroom, iLO's
  curve was just gentle at that reading. Publishing GPU + 10 C made them ramp
  earlier and held the case that had aborted at 78 C to 70 C.

## Results

Load was `llama.cpp` inference benchmarks (stock and Pascal-patched builds,
several models) with an independent 78-80 C abort guard.

| Setup | Result |
|---|---|
| No bridge, 160 W | aborted at 78 C within 1-3 minutes, with driver thermal slowdown |
| Bridge, no offset, 160 W, one model for 10 min | peak 77 C, then 67-72 C; no thermal slowdown |
| Bridge, no offset, 160 W and 140 W, full sweep | aborted at 78 C in the same hot case both times |
| Bridge, offset 10, 140 W, full sweep, both builds (about 62 min) | no abort; peaks 52-77 C, and the case that had aborted twice peaked at 70 C; no thermal slowdown |

Lifecycle paths seen on this host: an unclean kill, recovered on restart; a
host power cycle, after which the daemon claimed the slot afresh; `SIGKILL` under load, recovered; `SIGTERM` at idle, restored;
an exit under load ("iLO stopped tracking"), where the daemon kept its record
because the GPU had not cooled.

Not yet established here: registration after a power cycle without a manual
iLO reset, a counter wrap, and runs longer than a few hours.
